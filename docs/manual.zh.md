# Clipa 用户手册

版本：2.3.0（macOS 14+）

## 1. 产品简介

Clipa 是一款本地优先的 macOS 剪贴板工具：

- 自动记录你复制过的文本、JSON、YAML、Markdown、图片与文件；
- 通过 `⌃⌘V` 随时唤出居中浮动的历史面板；
- 支持备注与私密内容（加密存储）；
- 历史保存在本机 SQLite（`clips.sqlite`），默认不上传任何内容。

核心工作流只有三步：

```text
⌘C 复制 → 唤出面板搜索/选择 → 回车复制 → 目标应用里 ⌘V
```

> 说明：面板的"回车"是把选中内容**复制到系统剪贴板**，再由你手动 ⌘V，
> Clipa 不会拦截你在其它应用里的普通按键。

## 2. 安装与首次启动

1. 打开 `dist/Clipa-2.3.0.dmg`，把 `Clipa.app` 拖入"应用程序"；
2. 首次启动：菜单栏出现 Clipa 图标（文档图标），面板会自动打开；
3. 若系统提示"无法打开"，到"系统设置 → 隐私与安全性"允许来自本机开发者
   的应用，或执行：

```bash
xattr -dr com.apple.quarantine /Applications/Clipa.app
```

### 升级注意事项

- 替换新版本前，先退出正在运行的旧 Clipa（菜单栏图标 → 退出，或
  `killall Clipa`）；
- 旧版数据（`clips.json`）会在新版本首次启动时自动迁移到
  `clips.sqlite`，原 JSON 文件保留作安全副本；
- 更换应用后首次使用钥匙串可能重新弹窗，点"始终允许"即可。

点击菜单栏的 Clipa 图标可看到：

| 菜单项 | 作用 |
| --- | --- |
| 打开剪贴板面板（⌃⌘V） | 打开 / 收起剪贴板面板 |
| 工作区 ▸ | 切换 / 新建 / 重命名 / 删除工作区，打开数据目录 |
| 暂停记录 / 恢复记录 | 暂停或恢复剪贴板自动记录 |
| 忽略与跳过 ▸ | 一个模块收齐「什么不进历史」：① 忽略「<当前前台应用>」——点一下该应用复制的内容不再记录（已在清单里会显示"已忽略「X」"且不可点；判不出来时保持不可点并说明原因）；② 三条规则开关：跳过标记为机密的复制内容 / 跳过疑似敏感内容 / 跳过密码管理器复制的内容；③ 手动忽略清单，点一条即不再忽略它（若它仍被密码管理器规则覆盖，提示会说明） |
| 清空历史 ▸ | 「清空历史…」：确认框显示将删除 / 含私密条目数量；含私密内容时需 Touch ID / 系统密码验证；不可撤销。「清空时安全擦除（较慢）」：开关，清空时更彻底地擦除本机数据库残留。「历史条数上限…」：当前工作区最多保留多少条（0 = 不限制），达到上限后停止记录新内容，调低会立即删除较早条目（先确认）。「达到上限时自动暂停记录」：开关，到上限时自动暂停而不是静默丢弃，删除旧条目腾出空间后自动恢复 |
| 本地接口 ▸ | 开启控制面、新建令牌…、已授权程序…、最近调用…（详见 6.7；默认关闭） |
| 重建搜索索引… | 由 DDL / 归一化器指纹变化自动触发；也可手动重建 |
| 开机自启 | 注册 / 取消"登录时打开"（系统需要批准时会弹窗说明）。重装或更新后首次启动会自动重新登记，无需手动处理 |
| 退出 Clipa | 退出应用 |

> **2.3.1 起没有设置窗口**：原来设置里的项，能配置的都在上面这张菜单里；
> 历史条数上限、自动暂停阈值等保留为已保存的偏好，不再提供图形入口。

| 快捷键 | 作用 |
| --- | --- |

> 终端里的 readline quoted-insert、Vim 的 Ctrl+V（块选择）以及其它应用绑定在
> Control-V 上的操作全部保持原样。

> 2.3.0 起 Clipa **只有一个界面**：全部功能都由 `⌃⌘V` 唤出的面板承载；
> 2.3.1 起设置窗口也一并去掉，剩下的可配置项都在菜单栏菜单里。

## 5. 面板界面

### 5.1 剪贴板面板（⌃⌘V）

按 `⌃⌘V` 唤出：面板在鼠标所在屏**水平居中、垂直中心 54%** 处滑入（滑入滑出
有动画），悬浮在当前内容之上，失焦或再按 `⌃⌘V` 收起。

外观是**透明毛玻璃**：真实的窗口后模糊，桌面透得过来；选中不靠颜色加粗，
靠玻璃更亮；类型用冷色区分。想更"实"一点，可在「系统设置 → 辅助功能 →
显示」里打开「降低透明度」，面板会自动变成不透明底。
> 面板固定用浅色外观：即使 Mac 开着深色模式，它也是浅色面板。

- **顶部一行**：左侧品牌标记，中间是**居中的搜索框**，右侧是**暂停记录**；
- **结果列表**：纵向列表行（对齐 Spotlight 的行式布局），每行是
  「缩略图 / 文档小样（右下角带**来源应用徽标**）＋ 正文或文件名 ＋
  「类型 · 拷贝于时间」副标题」，行尾是回填按钮；选中行整行高亮；
- **键盘**：`↑`/`↓`（或 `←`/`→`）移动选中项——选中行自动滚进可视区；
  `↵` 复制并收起；`esc` 收起。搜索框里有内容时，`←`/`→` 归光标
  （带 `⌥`/`⌘` 的方向键始终归搜索框）。也可以直接输入，边打边筛；
- 搜索框按正文与备注做全文匹配，输入什么就找什么（中文子串、代码、URL 都可以）。

结果列表**滚到底自动加载下一页**（每次约 300 条），十万条级别的历史也能
一路滚到最早的一条；想快就直接用搜索框。

### 5.2 区域说明

- 顶部一行：品牌标记、居中搜索框、右侧**暂停记录**；
- 结果行：缩略图（图片按显示尺寸解码、上限 1024px 长边；文本是文档小样；
  文件 / 链接是对应图标）+ 右下角来源应用徽标 + 正文或文件名 +
  「类型 · 拷贝于时间」副标题（有备注时副标题直接展示备注内容，✎ 前缀）
  + 行尾回填按钮；敏感条目带 🔐 标记；
- 浮层编辑器：右键「添加 / 编辑备注」后，编辑框浮在面板底部
  （保存 / 取消都在那里完成）；
- 底部细条：`↵` 复制、`↑↓` 选择、`esc` 收起等快捷键提示，
  右侧是选中条目的类型 / 字符数、敏感提示与总条数。

### 5.3 选中与阅读

- 单击结果行即选中，方向键会自动滚动并选中；正文直接显示在行里；
- 双击不再触发粘贴（粘贴统一由"复制后手动 ⌘V"完成）；
- 右键条目可执行：复制、设为私密 / 解锁查看、添加 / 编辑备注、删除。
- **删除后停在原地**：删掉一行后，列表不滚动、也不跳回开头；
  选中落到它后面那条（删掉的若是最后一条，落到前面那条），你正在读的位置
  保持不变。

### 5.4 收起

- 按 `esc`，或再按一次 `⌃⌘V`；
- 点击面板以外的任何位置（其它应用、桌面）都会收起；
- 顶部一行（搜索框、菜单、按钮）不在这个范围内；
- 系统验证（Touch ID / 密码）弹窗出现时面板不会收起，验证结束后自动回到最前。

## 6. 功能模块

### 6.1 自动记录与类型

- 复制文本 / JSON / YAML / Markdown / 图片 / 文件后自动进入历史；
- 相同内容重复复制会自动去重并移到最前；
- 密码管理器复制的内容默认不记录（菜单栏 → 忽略与跳过 → 跳过密码管理器复制的内容 可关）；
- 开启「跳过疑似敏感内容」（菜单栏 → 忽略与跳过）后，检测到 API Key / Token /
  私钥等不再记录。

### 6.2 智能识别与敏感标记

- 系统会为内容打上更细的显示标签：文本、JSON、YAML、Markdown、图片、
  文件；链接、代码、日志、Shell 命令、IP、邮箱都归入文本，不再单独分类；
- 命中 API Key、AWS/GitHub/Slack Token、Bearer Token、私钥等内容时，
  条目的信息行显示 🔐"敏感"提示；
- 识别规则已内置回归测试（见《测试案例》文档），可在复制后立即核对条目图标。

### 6.3 备注

- 右键"添加 / 编辑备注"，之后可用备注内容搜索，适合给密码、验证码、
  地址等添加别名；
- 编辑器打开时键盘就归它：`⏎` 保存、`esc` 取消；浮层右上角会显示你正在改哪一条
  （类型 + 一小截正文；私密条目只写"私密 · 已解锁"）；
- 备注只参与搜索与显示，不改动正文，也不会让条目免于淘汰或清空。

### 6.4 搜索

搜索框只匹配两类字段：**正文**（复制到的内容）与**备注**。普通本地搜索把
搜索框内的完整内容当作**一个整体关键词（短语）**，正文或备注中必须包含该
完整内容（大小写不敏感）：

示例：

```text
kubernetes 部署     → 正文连续包含 "kubernetes 部署"
192.168            → 正文包含 192.168 的内容
周报素材           → 备注包含"周报素材"的内容
```

普通短语搜索优先走 SQLite FTS5 全文索引；短语过短时自动回退到内存搜索，
结果保持一致。

搜索完全按字面进行：输入 `yaml` 就找正文里出现 `yaml` 的条目，不会把它当成
"按格式筛选"的指令。全部在本机完成，不联网、不发送任何内容。
### 6.5 富文本与本地处理

> 富文本在采集时已经转为纯文本，因此历史条目本身即为 Plain Text。这个转换
> 在本机后台完成，并且**不会联网**：网页里的图片、样式表、CSS `url()` 这类
> 引用会先被去掉再解析，所以复制一个带图的网页不会让 Clipa 去下载任何东西。
> （"格式化 JSON""JSON ↔ YAML 转换"等本地转换功能已移除，右键菜单不再提供。）

### 6.6 私密夹：加密存储（Touch ID / 系统密码）

> **它是什么**：私密条目的**正文与备注以密文保存在本机数据库**，密钥存在
> **本机钥匙串**（`…ThisDeviceOnly`、不随同步或备份离开这台机器）。把
> `clips.sqlite` 或它的备份拿走，只能看到密文。锁定时不展示正文，
> 复制、取消私密、删除都要过一遍系统验证。

**它的代价与边界**（同样是它的一部分，别只读上面那句）：

- **恢复到另一台机器上读不回来**：密钥不随数据库走。这是加密的定义，不是缺陷——
  但它意味着"备份 + 换机"时私密内容会变成无法解开的密文；
- **私密内容搜不到**：搜索索引（FTS 与归一化列）里不留第二份正文副本，所以它在
  取消私密之前不参与检索。这与 6.7 的本地接口一致（接口本来就不返回私密内容）；
- **图片字节已加密（2026-10-02）**：私密图片与正文/备注一样以密文落盘；
  原先的"派生快捷片段"功能已整体移除（它在界面上本就没有入口）；
- 应用以你的身份运行时，内存里是明文：它挡的是"拿到文件的人"和"旁边的人"，
  不是"同机同用户的其它进程"。要后者请配合 FileVault。

1. 右键条目 → "设为私密"；
2. 锁定状态下，列表行以烟熏玻璃压住缩略图（显示锁徽标，标题为
   「已上锁的私密条目」），正文与备注都不显示；
3. 解锁有两条路径，都会请求 Touch ID / Mac 密码：右键"解锁查看（60 秒）"，
   或直接对条目执行"复制"（复制前会先验证）；
4. 解锁仅对当前这一条生效：60 秒内可浏览/复制该条，随后自动重新上锁；
   其它私密条目与之后新设为私密的内容始终各自保持锁定；
5. 右键"取消私密"前会再次请求 Touch ID / Mac 密码，验证通过后才能移出
   私密夹；验证取消后私密状态保持不变，面板仍停留在当前界面。
6. 删除私密条目同样需要重新完成一次系统验证，不能复用 60 秒查看解锁窗口；
   验证取消后条目保持不变。
备注与正文一样被私密遮挡覆盖：锁定时备注不展示，添加/编辑备注会先
请求解锁；解锁超过 60 秒自动上锁时，尚未保存的备注编辑也会被关闭。

私密标记与密文都保存在本机 SQLite 中，不上传、不入云；密钥只在钥匙串里，
不进数据库文件。

还有一处值得知道（它是上面"搜不到"的另一面）：锁定的条目**仍然留在列表里**，
它没有被隐藏、也没有被删除 —— 但**不参与检索**。库里不留第二份可检索的明文，
索引层就没有它的正文可匹配。想按内容找到锁起来的东西，先解锁它
（右键 →"解锁查看（60 秒）"）。

### 6.7 本地控制面（供程序调用）

Clipa 可以把历史交给本机的其它程序（包括 AI Agent）用：打开**控制面**之后，它们能按
**令牌 + 作用域**查询、复制、写入。**默认关闭**，要你手动打开一次。

> **原先还有一档「只读导出」，已于 2026-09-26 移除。** 它把最近 100 条写成一份脱敏 JSON
> （`api-export.json`，权限 `0600`）放在库目录里 —— 而**任何以你的身份运行的程序都能
> 直接读它**：不需要令牌、不会在审计里留下记录、也不受作用域约束。控制面的目标恰恰相反
> （"唯一合法读数路径"），两档不能并存。升级后首次启动会自动删掉盘上残留的那份旧文件。

一条规矩先说清楚：**整个历史库自 2026-10-04 起以密文落盘（SQLCipher 整库加密，
密钥在本机钥匙串）**——把库文件或它的备份拿走，读不出任何历史内容（私密夹更早，
2026-09-26 起字段级密文，见 6.6；控制面本来就不返回私密内容）。控制面把**授权路径、
作用域、审计、撤销**这四件事补齐了，但它不是一道能挡住同机其它进程的墙。

#### 用法

1. 菜单栏图标 → 本地接口 → 勾选「**开启控制面**」；
2. 「**新建令牌…**」：写名字（例如 `Claude Code`）、勾作用域。**令牌只显示一次**，
   弹窗里可直接点「复制 Cursor 配置」「复制 Codex 配置」——片段已内嵌令牌，
   粘贴进 `~/.cursor/mcp.json` 或 `~/.codex/config.toml` 即完成接入；
   也可手动写环境变量 `CLIPA_TOKEN=<令牌>`，或文件 `~/.config/clipa/token`
   （权限 `0600`）；
3. 命令行工具在 `Clipa.app/Contents/Helpers/clipa`。想直接用 `clipa` 这个名字就做个软链：
   `ln -s /Applications/Clipa.app/Contents/Helpers/clipa /usr/local/bin/clipa`；
4. **AI 工具接入（MCP）**：在 Claude Code / Cursor 等的 MCP 配置里加一段即可，无需写代码：

   ```json
   { "mcpServers": { "clipa": {
       "command": "/Applications/Clipa.app/Contents/Helpers/clipa-mcp" } } }
   ```

   Agent 会得到六个工具（状态 / 检索 / 读取 / 复制 / 写入 / 备注），令牌、
   作用域、审计与面板看到的顺序完全一致。

```bash
export CLIPA_TOKEN=…                        # 或写进 ~/.config/clipa/token
clipa status                                # 接口状态与当前令牌的作用域
clipa search "docker compose" --limit 5     # 检索（排序与面板一致）
clipa search "" --limit 50 --offset 50      # 翻页：第 51–100 条（配合结果里的 total/next_offset）
clipa get <id> --json                       # 取一条
clipa copy <id>                             # 放回系统剪贴板
clipa delete <id>                        # 删除一条（需 delete 作用域，不可恢复）
echo "内容" | clipa put --label "Claude"    # 写进历史，来源标成 Agent: Claude
clipa note <id> --text "说明"               # 写备注
```

`--json` 下错误也是 JSON（同时给出退出码）：`0` 成功 · `1` 其它 · `2` 未授权 ·
`3` 接口未开启或应用没在跑 · `4` 被策略拒绝 · `5` 协议版本不符。

#### 作用域

| 作用域 | 允许 |
| --- | --- |
| `search.meta` | 检索，只返回元信息（时间 / 来源 / 类型 / 是否敏感），**不含正文** |
| `search.text` | 检索，返回正文开头 **8 字节**的指纹片段（够区分条目、不够阅读；取整条需 `read.full`） |
| `read.full` | 取单条时返回整条正文（`get` 需要这个作用域） |
| `copy` | 把某条放进系统剪贴板 |
| `put` | 把内容写进历史 |
| `note` | 写备注 |

新令牌默认只勾前两个，后四个（其中三个是写）要单独勾。

#### 它会拒绝什么

- **私密条目**：任何动词都取不到 —— 而且返回的错误与"这条不存在"**完全一样**，
  免得有人拿 id 试探私密内容是否存在；
- 被判定疑似敏感的内容**不能通过 `put` 写进来**：它走的是
  和正常复制完全相同的那道闸；
- 需要系统验证的操作（解锁私密、删除、清空历史）**不开放**，也不会弹窗；
- 每个令牌每分钟最多 60 次调用。

#### 审计

每次调用记一行（`~/Library/Application Support/Clipa/api-audit.jsonl`，权限 `0600`）：
时间、令牌名、调用方（可执行路径 + pid）、动词、查询的前 80 字、命中数、被拒原因。
**正文永不入日志**。菜单里「最近调用…」能直接看，也能清空。

`copy` 有一个不显眼但重要的性质：它走的是 Clipa 自己的写入器，所以**不会在历史里多出一条**
（否则每次 Agent 调用都会把你的历史刷成它自己的输出）。

> 顺带一条给 Agent 的建议：**要凭据就用 `copy`，不要用 `get`** —— 内容直接回到剪贴板，
> 模型上下文里不留副本。

### 6.8 全本地，无 AI

Clipa 不包含任何 AI 功能，也不联网：搜索完全由本地规则解析，全部处理都在
这台 Mac 上完成。没有账号、没有 API Key、没有需要配置的模型。

## 7. 设置在哪里

**2.3.1 起没有设置窗口**。留下来的可配置项都在菜单栏图标的菜单里（第 3 节）：

### 忽略与跳过（菜单栏 → 忽略与跳过）

「什么不进历史」只有这一个模块，里面自上而下是三组：

**① 一行动作：忽略当前前台应用**

- 标题里直接写出会忽略谁——`忽略「Safari」`；
- 若该应用**已经在清单里**，这一行变成 `已忽略「Safari」` 并且**不可点**，不会再让你
  做一次无效的点击；
- 若判不出来（Clipa 自己是前台且还没见过其它应用、或该应用没有 bundle ID），
  这一行保持不可点，鼠标悬停会说明原因，而不是点下去才失败。

**② 三条规则开关**

- **跳过标记为机密的复制内容**（默认开）：来源应用自己在剪贴板上打的
  "不要记录"标记（`org.nspasteboard.ConcealedType` / `TransientType`），
  密码管理器、浏览器密码框、终端输密码提示都会打。它不依赖应用名单，
  所以一个没被列入任何清单的工具复制出来的密码同样不会被记录；
- **跳过疑似敏感内容**（默认关）：命中 API Key / Token / 私钥等本地规则的内容
  不再记录（未开启时仍会记录，只是卡片上带 🔐 标记）；
- **跳过密码管理器复制的内容**（默认开）：内置一份保守名单——1Password、
  Bitwarden、KeePassXC、LastPass、Dashlane、Passwords.app、钥匙串访问。
  它是一条**应用名单规则**，所以和上面两条内容规则放在一起，而不是塞在手写清单里。

**③ 手动清单**

- `不再忽略 <应用>`：点一条即把它移出清单。若那个应用同时被
  「跳过密码管理器复制的内容」覆盖，提示会说明"仍由……覆盖"，而不是假装已经放行
  ——只移除自定义这一条，并不会让它被重新记录；
- 清单为空时显示一行不可点的「（还没有手动忽略的应用）」。

### 数据

- **清空时安全擦除**（默认关）：清空历史时更彻底地擦除本机数据库残留，降低被
  恢复的可能；处理时间更长，系统备份中的旧副本不受影响；
- **重建搜索索引**：一般不需要手动执行，索引由 DDL 与归一化器指纹变化自动重建；
- **打开数据目录**：菜单栏 → 工作区 → 打开数据目录。

### 系统

- **开机自启**：注册"登录时打开"。系统需要批准时会弹窗提示去
  「系统设置 → 通用 → 登录项」允许；从 `/Applications` 之外运行时系统会拒绝注册，
  弹窗里会说明。

> **仍然生效但已无图形入口**的偏好（沿用本机已保存的值）：历史条数上限
> （默认 500）、达到上限时自动暂停记录的开关。需要改动时，
> 目前只能改 `~/Library/Preferences` 下 Clipa 的偏好项。

## 9. 数据与隐私

- 历史：`~/Library/Application Support/Clipa/clips.sqlite`
- **整库加密（2026-10-04 起）**：历史库以 SQLCipher 密文落盘，密钥在本机钥匙串
  （`ThisDeviceOnly`）。首次打开会自动把旧明文库迁移为密文库，原文件保留为
  `clips.sqlite.plain-backup`——确认一切正常后可自行删除；
- 与私密夹同样的边界：**库文件随备份/换机离开本机后不可解**（换机请先在本机导出）；
- 图片：存在 `clips.sqlite` 内（自 v7 起）；旧版本遗留的图片文件会迁移后
  重命名为 `~/Library/Application Support/Clipa/images-migrated-v6/`
完全本地优先：不注册账号、不上云、不联网，也不会把任何内容发给任何服务。
开启「跳过疑似敏感内容」（菜单栏 → 忽略与跳过）或把条目设为私密，可以减少敏感内容
被看到的机会，但两者性质不同：跳过是**不进历史**，私密是**进了历史但以密文落盘**
（正文、备注与图片字节都加密，见 6.6）。

图片以复制时的原始格式保存（只有粘贴板给的 TIFF 会转成 PNG），所以从
Clipa 复制出去的图片与来源一致：EXIF、动图、矢量内容都不会被改写。文件
类型（Finder 里的文件）仍然只保存路径引用，原文件被移动或删除后会提示
不可用。

## 10. 常见问题（FAQ）

### 复制了内容但历史里没有？

依次检查：

1. 菜单栏"暂停记录"是否开启；
2. 该应用是否在菜单栏「忽略与跳过」的清单里（或曾是当前前台应用且被忽略）；
3. 是否来自被默认忽略的密码管理器；
4. 是否开启了「跳过疑似敏感内容」且内容命中敏感规则；
5. 内容是否是在 Clipa 启动前复制的（Clipa 只记录启动后的复制）；
6. **当前工作区**：Clipa 支持多个工作区，记录进的是"当前活动工作区"的库
   （菜单栏 → 工作区 可切换）。在 A 工作区复制的内容不会出现在 B 工作区里。

想确认"到底有没有记下来"，可以在「控制台 / Console」里搜 `Clipa capture`：
Clipa 会打印**不含任何内容**的判定日志 —— `pasteboard change N → M`（看到了
剪贴板变化）、`capture accepted: kind=… source=…`（已接受并入库）、
`capture skipped: <原因>`（被暂停 / 忽略名单 / 机密标记 / 无内容挡下）。

### 面板开着的时候在别处复制，会记录吗？

会。面板打开时 Clipa 自己是前台应用，但你在别处的复制（截图、其它应用的复制）
仍然会正常入库，来源记为**你打开面板前正在用的那个应用**。只有 Clipa 自己把
你选中的条目写进剪贴板（在面板里按 `↵` 复制）那一次不会重复记录。

### 点其它应用后面板消失了？

这是设计行为：面板是浮层，点击面板以外的任何位置都会收起，避免挡住
你正在用的应用。需要时按 `⌃⌘V` 或点菜单栏图标再次唤出；
面板收起后搜索词和选中项都会保留。

### Touch ID 弹不出？

确认系统已启用密码 / Touch ID；私密内容解锁依赖系统认证能力。
